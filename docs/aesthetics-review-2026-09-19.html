B5主按钮 hover 分叉（复制漂移实例）

关联发现：E3。TableToolbar.vue:116-129 vs EditorDrawer.vue:801-821。悬停模拟格 = 按特异性计算出的实际渲染结果。
现状 · 同名"主按钮"两处 hover 结果相反
批量条「▶ 连接」（bb-primary）——hover 后 accent 边框丢失
常态：accent 边框
hover：边框退化为
--border-strong
抽屉「保存」（ed-primary）——hover 保留 accent 边框
常态
hover：accent 边框保留
原因：.bb-btn:hover:not(:disabled)（特异性 0,3,0）的 border-strong 压过 .bb-primary（0,1,0）；EditorDrawer 侧补了 .ed-primary:hover 守卫。明显的非有意分叉。
建议 · 统一主按钮 hover 规范
常态：accent 边框 + accent 文字
hover：accent 边框保留
+ bg-hover 底
最小修复：为 .bb-primary 补 :hover:not(:disabled)（2 行，对齐 ed-primary）。规范入令牌注释：主按钮 hover = accent 边框 + --bg-hover + accent 文字。

主按钮同样
无 hover 强化
对照：同文件 .en-clear（无匹配清除按钮）有完整 hover；列表批量条、抽屉保存按钮都有 hover。空库/离线/无匹配三个空态共用此缺口。
建议 · 补齐与全站一致的 hover
hover：border-strong
+ bg-hover + text-1
hover：accent 边框
+ bg-hover
纯增量 2 条规则（.eg-btn:hover / .eg-primary:hover），无功能影响，直接提升首启动引导的可用性观感。

B12搜索高亮 .hl：7 强调色 × 双基底稳健性矩阵

light 基底

light 基底
