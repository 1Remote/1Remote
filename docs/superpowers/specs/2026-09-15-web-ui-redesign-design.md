# 1Remote Web UI 重设计 — 设计文档（Spec）

- **日期**：2026-09-15
- **状态**：已与项目作者逐节确认（视觉样张 5 张 + 文字 4 节全部通过）
- **上游文档**：`docs/web-ui-migration-assessment.md`（迁移评估，2026-09-15）
- **目标读者**：项目作者（实现者本人）、未来的实现计划（writing-plans 产物）

## 1. 目标与约束

### 1.1 目标（按优先级）

1. **用户体验提升**：相比 WPF 版管理界面，操作效率、反馈即时性、视觉现代感全面优于现状。
2. **UI 可维护性提升**：前端实现简单、依赖少、单人（前端初学者）可长期维护。

### 1.2 硬约束

- 功能与 WPF 版一致（UI 呈现可以不同）。
- 保留主题切换（配色切换）能力，且演进为更现代的形态（见 §4）。
- 文本全面国际化（大量海外用户，现 WPF 版 14 种语言）。
- 技术栈基座：Vue 3 + Vite + JavaScript + Naive UI（2026-09-15 头脑风暴中用户确认；**取代**评估报告 §7.1 当时推荐的 Element Plus）。
- 运行形态：WPF 壳 + WebView2 承载 Web UI，本地进程内 HTTP 服务（评估报告方案 B）。

### 1.3 范围内页面

服务器列表页（主界面）、连接编辑器（9 种协议）、设置页（7 个分组导航：常规/启动器/数据源/凭据库/外观/运行器/语言与关于——凭据库是设置页内的独立分组页，详见 §6）、标签管理（边栏标签区的管理模态）。

### 1.4 范围外（明确不迁移，保持桌面实现）

`View/Host/` 全部、`LauncherWindowView` 及 `View/Launcher/` 子视图、`ErrorReport`、`Guidance`、系统托盘、全局热键、开机自启。

### 1.5 有意裁剪

- **卡片视图**：不再实现（用户决策 2026-09-15）。内容区只保留行列表；原三视图（卡片/行/树）重组为"边栏树 + 行列表"。
- **快速连接（host:port 直连）**：保留在桌面端 Launcher 中；Web 端不重复实现（同等能力可经"新建连接"达成）。
- **RequestRating 弹窗**：保留在 WPF 壳层（触发点是主窗口关闭行为，属于壳）。

## 2. 视觉风格

**Linear 暗色工具风**（用户从 4 个风格样张中选定）：

- 克制配色：中性灰阶为基底，低饱和强调色；无大面积彩色。
- 细边框（1px `#26272b` 级）分隔层次，几乎不用阴影（浮层除外）。
- 紧凑信息密度：行高约 36px（含 padding），字号基准 12.5px。
- 圆角语言：控件 6-7px、卡片/浮层 8-10px、胶囊 99px。
- 键盘优先气质：快捷键提示随处可见（`Ctrl K`、`Enter`、`E`…）。
- 动效克制：150-200ms 过渡；仅抽屉滑入、页签切换、toast 有动画。

## 3. 布局与信息架构

### 3.1 主界面骨架（1280×800 基准）

```
┌────────────────────────────────────────────────────────────┐
│ 顶栏 44px：Logo │ 搜索框(Ctrl K) │ 新建 排序 列 │ ⚙        │
│  搜索在服务端执行，复用 KeywordMatchService（拼音/多关键词/#tag 语法），前端不自写过滤 │
├──────────┬─────────────────────────────────────────────────┤
│ 边栏     │ 面包屑（数据源/文件夹路径）+ 批量操作条(≥1选中) │
│ ~220px   ├─────────────────────────────────────────────────┤
│ 可收起   │ 行列表（表头可排序/调列宽）                       │
│          │ …                                                 │
│ 树       ├─────────────────────────────────────────────────┤
│ +标签区  │ 底部状态栏：各数据源同步状态 · N台 · M标签       │
└──────────┴─────────────────────────────────────────────────┘
```

### 3.2 边栏树（用户 4 点修正后的最终形态）

- **数据源 = 根节点**，多数据源并列常驻：`🗄 Local · SQLite`、`🗄 MySQL · 生产库`…
  每个根节点带连接状态点：绿=已连接、灰=空闲、红=断线（附重连倒计时，如 `重连 38s`）。
- 根节点下为文件夹树（无限层级），叶=服务器；节点右侧显示子项计数。
- **选中根节点**：内容区显示该库全部服务器，面包屑为「数据源名 · 全部服务器 · N 台」，列表出现「文件夹」列显示归属路径；**选中文件夹节点**：面包屑为「数据源 / 文件夹路径」，「文件夹」列自动隐藏，列表显示该文件夹下（含子文件夹）全部服务器。
- 树节点交互：单击=选中过滤内容区；双击服务器=连接；右键=菜单（新建/重命名/编辑/复制/删除/连接）；拖拽=移动与排序（语义见 §3.5）；三态勾选框（勾选文件夹=级联选中其下全部）用于批量操作。
- 展开状态、自定义顺序持久化（复用 `LocalityTreeViewService`）。
- 边栏底部：「« 收起边栏」；收起后变为 44px 图标条（树/标签/设置入口），窗口 <900px 时自动收起。

### 3.3 边栏标签区

- 树下方「标签」区：胶囊标签 + 计数（`生产环境 12`），置顶标签排前。
- 单击标签=设为过滤条件（内容区顶部显示过滤 chips，可排除 `-#tag`）；`+ 管理`打开标签管理模态（置顶/重命名/删除/连接全部/桌面快捷方式——对齐 WPF TagsPanel 功能）。
- 取代 WPF 版独立 Tags 页签。

### 3.4 行列表（内容区唯一视图）

列定义（默认顺序，可在「列」菜单中配置显隐与顺序）：

| 列 | 说明 |
|---|---|
| ☑ | 复选框，Ctrl 单选/Shift 范围选 |
| 状态 | **预留**：已连接(绿点)/连接中(黄)/离线(灰空心圈)；数据接口预留 `connectionState` 字段，后端功能就绪前恒显示「—」 |
| 名称 | 22px 服务器图标（内置库/本地图片/exe 提取，Base64；底色=服务器自定义色的低饱和变体；未设图标时用协议默认图标）+ 名称 |
| 地址 | `192.168.1.10:3389` |
| 协议 | 胶囊徽章（RDP/SSH/SFTP/FTP/VNC/Telnet/Serial/APP/RdpApp），每协议固定配色 |
| 标签 | 胶囊 |
| 文件夹 | 仅根节点视图显示，如 `生产环境 / Web 集群` |
| 最近连接 | 相对时间（Intl 本地化），如「2 小时前」 |
| 操作 | hover 显示：▸ 连接、✎ 编辑、⋯ 更多 |

- 表头点击排序（名称/地址/协议/最近连接），地址列用自然 IP 排序比较器（移植 `SubTitleSortByNaturalIp`）；列宽可拖拽；排序与列宽持久化。
- 行 hover 高亮 + 行内操作浮现；右键菜单（连接/新窗口连接/其他凭据连接/编辑/复制/复制地址/复制用户名/复制密码/桌面快捷方式/删除，带快捷键提示）。
- **批量操作条**：选中 ≥1 台时在面包屑右侧展开（连接/批量编辑/导出/取消选择+已选计数），取代 WPF 版底部滑出面板。
- 底部状态栏：各数据源同步状态点 + 台数/标签数统计。
- 虚拟滚动：数据 >500 行时启用（`useVirtualList`），此前直接渲染。

### 3.5 拖拽语义（对齐 WPF 版并做一期简化）

- 树内拖拽（一期简化）：拖到目标上悬停=移入；目标上下边缘 25% 区域=前插/后插；跨数据源/移入自身后代/只读库=不高亮不响应（WPF 版为光标语义，Web 用高亮与否表达）；同名文件夹合并、后代环检测规则不变。
- 行列表自定义排序（仅排序模式=Custom 时）：行拖拽上/下半区=前插/后插，语义与 WPF 版一致。
- 均落盘既有持久化（`LocalityTreeViewService.CustomNodeOrder` / `LocalityListViewService.ServerCustomOrder`）。

## 4. 主题系统（双轨制）

- **基底**（`[data-theme="dark|light"]`，跟随 `prefers-color-scheme` 可选）：约 20 个 CSS 变量（背景、面板、边框、文字灰阶 4 档）。
- **强调色**（`[data-accent="blue|violet|pink|red|orange|green|slate|自定义"]`）：主色、主色 hover、主色容器底色等 6-8 个变量。
- Naive UI 通过 `themeOverrides` 消费同一套变量；换主题=换 data 属性，无重渲染。
- **旧 9 主题映射**为预设组合（设置页「经典主题」一排可达）：Light=浅+蓝、Dark=深+蓝、Wine=浅+酒红、Forest=深+墨绿、Greystone/Asphalt=深/浅+石板灰、Soil=浅+赭黄、SecretKey/PRemoteM=浅/深+对应主色。观感不逐色还原，语义保留。
- 字号 S/M/L/XL（对应现有 GlobalFontSize 四档）、界面字体（系统字体下拉）沿用；全部持久化到 `1Remote.json`（经 API 写入，桌面侧同步生效）。
- 服务器自定义颜色独立于主题，不受切换影响。

## 5. 连接编辑器（抽屉）

- 形态：右侧滑出抽屉，宽 68%（可拖边缘，560px~900px）；左侧列表压暗保持上下文。小表单（图标选择、凭据编辑、参数编辑、数据源选择、标签管理）用居中模态。
- 抽屉头：服务器图标 + 「编辑：名称」+ 归属路径与修改时间 + **协议切换下拉**（切换时沿用现有"按公共基类保留字段"逻辑）+ 关闭。
- 分组页签（带未保存小圆点）：RDP=基本信息/显示/网关/高级/备注；其他协议按各自分组（SSH=基本/启动行为/Runner…），共 9 组协议表单共用抽屉骨架。
- 字段排版：标签在输入框上方、两列网格、必填 `*`、枚举用下拉、开关用 toggle、rdp 附加设置多行文本（一期普通 textarea，CodeMirror 补全二期）。
- 凭据折叠卡片：手动输入 ⇄ 凭据库下拉（两种来源切换）+ 用户名/密码/域 + 私钥（SSH 类）+ 备用凭据列表 + 连接时询问密码。
- 图标 + 颜色行：图标选择（网格弹窗，服务端支持 exe/ico 提取）+ 颜色选择。
- **批量编辑显式化**：多值不同字段显示「‹ N 台各不相同 ›」斜体占位 + 字段级「保持不变 ▾ / 覆盖」选择；保存合并逻辑对齐 WPF 版（反射合并 + Tags/凭据/参数列表求交集），移植时补单元测试。
- LocalApp 动态字段：字段显隐由参数宏（`%1RM_HOSTNAME%` 等）引用推导，规则不变。
- 键盘：Ctrl S 保存、Esc 关闭（有修改时弹确认）；保存成功 toast + 列表就地刷新。

## 6. 设置页

- 全屏视图（覆盖内容区），左侧分组导航：常规 / 启动器 / 数据源 / 凭据库 / **外观** / 运行器 / 语言与关于；Esc 或「← 返回」回列表。
- 分组内容对齐 WPF 版设置项清单（评估报告 §4.4）：常规（语言、自启、关闭行为、安全开关、日志…）、启动器（热键注册由本地进程执行，设置保存后经 API 重注册）、数据源（增删改查 + 测试连接 + 状态，SQLite 路径走本地文件对话框 API）、外观（§4 全部）、运行器（每协议 Runner 列表 + 外部运行器编辑：exe 路径/参数宏/环境变量/Hosting 开关；参数宏编辑一期为普通 textarea）、语言与关于（语言切换、版本、更新检查、开源许可）。
- **凭据库**（独立分组页）：凭据表格（名称/用户名/地址/被引用计数/操作）+ 数据源过滤下拉 + 新建/编辑模态；删除被引用凭据需确认（提示联动影响）；**明文查看**：点击 👁 → 请求 API → 本地进程弹 Windows Hello/Windows 凭据验证 → 短时效（30s）内返回明文，网页不缓存；只读数据源中禁用编辑。

## 7. 国际化（i18n）

- **vue-i18n**；`src/locales/{lang}.json`，14 语言文件入仓，社区 PR 贡献翻译（延续现有协作模式）。
- 一次性脚本把 `Ui/Resources/Languages/*.xaml` 转为 JSON，**键名沿用**，翻译资产零损失；缺失键回退 en-US。
- 界面语言：默认跟随系统（`navigator.language`），设置页可覆盖；切换即时生效（无刷新）。
- 相对时间、日期、数字用浏览器 `Intl` 按当前语言格式化。
- 布局规范：所有文案容器弹性宽度；按钮/页签/表头禁止固定宽度（防德语等长文案破版）。
- 样张中的中文均为示意；实现时界面零硬编码文案。

## 9. 前端架构（可维护性）

### 9.1 技术栈（锁定）

Vue 3（`<script setup>` 组合式 API）+ Vite + JavaScript + Naive UI + vue-router + vue-i18n + **@vueuse/core**（虚拟滚动 `useVirtualList` 等）+ **vuedraggable**（SortableJS 封装，树/列表拖拽）。
**不引入**：Pinia、TypeScript、axios、Tailwind（组合式函数 + 模块级共享状态 + 原生 fetch 足够）。

### 9.2 目录结构

```
src/
├─ api/            # fetch 封装 + SSE 订阅 + 接口定义（1-2 个文件）
├─ themes/         # CSS 变量定义 + 旧主题映射表 + themeOverrides（1 个文件）
├─ locales/        # 14 个语言 JSON（社区可贡献）
├─ composables/    # useServers / useTheme / useLocale / useSelection / useTreeState
├─ components/     # ServerRow、ProtocolBadge、StatusDot、TagChip、IconPicker、CredentialCard…
└─ views/          # ServerListView / EditorDrawer / SettingsView / CredentialVaultView / TagManagerModal
```

- 组件单一职责、scoped CSS + CSS 变量；composables 承载全部状态与业务逻辑（对应 WPF 的 ViewModel 心智）。
- 页面骨架预计 4000~6000 行（对比 WPF View 层约 2 万行）。

### 9.3 与后端契约（概要，详细接口在实现计划中定义）

- REST：`/api/servers`（列表/CRUD/批量）、`/api/connect`（发起连接，含 need_password 续答流）、`/api/credentials`、`/api/settings`、`/api/tags`、`/api/datasources`、`/api/files/*`（文件对话框/导入导出）。
- SSE：`/api/events` 推送数据版本号与数据源状态变更。
- 鉴权：`127.0.0.1` + 启动随机 token（评估报告 §6）。

## 11. 风险与开放问题

1. **拖拽重写**是最大工作量与风险点（树移动/排序语义），一期语义简化（§3.5），二期对齐 WPF 精度。
2. 批量编辑合并逻辑移植必须带单元测试（放 `Tests/` 工程）。
3. Naive UI `themeOverrides` 与双轨变量的映射需在阶段 0 验证。
4. 14 语言 JSON 转换脚本的正确性（XAML 转义、缺失键回退）。
5. `connectionState` 为纯预留：接口字段与列 UI 先行，后端会话状态上报属后续后端任务。
6. REST/SSE 契约细节（错误码、续答流状态机）在实现计划阶段定义，含 `need_password` 流程。

## 12. 验收标准（设计层面）

- 全部 WPF 管理功能在新 UI 中可达（映射表 §10 全覆盖，裁剪项有据）。
- 主题切换（基底+强调+经典预设+字号+字体）与深浅跟随系统可用。
- 14 语言切换可用，无硬编码文案。
- 键盘流（§8.2）完整可用。
- 视觉还原 §2 风格与 5 张已确认样张（存档于 `.superpowers/brainstorm/`，正式视觉规格以本文档 §2-§6 描述为准）。
